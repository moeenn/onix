## Onix

## Setup

```bash
// install system dependencies.
$ sudo apt-get install libadwaita-1-dev librust-gtk4-dev libglib2.0-dev

// build project.
$ cargo build --release

// run app.
$ ./target/release/onix
```

## Install

```bash
// build and install for the current user (binary, launcher and icon).
$ ./install.sh
```
